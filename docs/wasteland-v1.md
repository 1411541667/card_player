# 末世首版内容说明

## 开局流程

- 选择拾荒者；另外两个角色作为不可选占位。
- 从六项开局增益中随机三选一。
- 选择尘沙主题；暗林和寂原作为不可选占位。
- 拾荒者：80最大生命、每回合3行动力、200商店代币，并初始拥有拾荒者的布袋。

## 单局结构

- 四层区域，每层按种子生成12–20个节点，数量包含首领。
- 每层2–3个商店、4–6个物资节点；其余普通节点按战斗40%、事件60%分配。
- 玩家只能选择当前节点连接的下一节点，不能回头或重复进入。
- 路径在斜俯视地图中以虚线连接；每层所有末路汇入该层唯一首领。
- 击败首领后进行三选一奖励；前三层领奖后进入下一层，第四层领奖后结算。

## 战斗与奖励

- 初始牌组：挥砸×4、闪躲×4、呼唤队友×1、愤怒×1。
- 初始抽牌和每回合基础抽牌均为5，手牌上限10。
- 防护在整场战斗中保留并累计，战斗结束后清空。
- 攻击牌可强化两次；第二级最终数值为基础值加两倍的第一级增量。其他牌可强化一次。
- 普通战斗胜利固定给予20–60商店代币，不进入奖励选择。
- 首领战和未来的精英战胜利提供三个不重复候选，必须三选一。

## 评分

分数只在结算页显示：节点×10、战斗胜利×40、首领×200、完成楼层×150、剩余生命×2，完整胜利另加800。每100分折算1个局外代币。

局外代币、角色/卡牌解锁、生命和初始资源升级的数据与存储接口已提供；本阶段不开放正式养成购买UI。百科内容在游戏中首次遇见后解锁，统计只保留最近三局。

## 内容数据

- 人工编辑源：`src/content/wasteland/tables/`
- 运行时JSON：`src/content/wasteland/data/`
- 执行 `npm run content:sync` 从CSV同步可编辑数值到JSON。
- 构建和测试会执行 `npm run content:check`，CSV与JSON漂移时失败。
- “沾染血迹的信”已作为剧情收集品和第四层隐藏首领条件接口保留；隐藏首领内容暂未实现。
